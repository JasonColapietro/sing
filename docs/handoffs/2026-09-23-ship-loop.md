## Pitch-precision harness (S0a)

- `lib/audio/voice-fixture.ts`: a deterministic synthetic voice (harmonics,
  detune, vibrato, jitter, noise) plus a WAV encoder, shared by both layers
  below.
- `lib/audio/pitch-precision.test.ts`: C2–C6 at 44.1/48 kHz. Ceilings are
  measured values with headroom, and each figure is recorded in the file
  header.
- `npm run e2e:pitch` (`e2e/pitch-precision.mjs`): runs 12 cases through
  Chrome's fake microphone into `/studio`. It reads what `usePitch` heard via
  `window.__singPitchProbe`, a hook that does nothing unless the harness
  creates it. Usage and measured values are in `e2e/README.md`.

Measured: clean notes read within 0.2 c with no octave errors. At 10 dB SNR the
error reaches p95 16 c and max 31 c, and 2 of 294 frames are missed.

## S1 (pitch engine), built directly

- **Median bias fixed.** `lib/audio/median.ts` averages the two middle values.
  It's used by `usePitch`, ear-game note segmentation and the
  spectral-envelope F0, which all took the upper middle value before.
  Browser vibrato bias went from 5.5 c sharp to 0.7 c (ceiling 1.5 c).
- **Noise weak spot fixed.** `detectPitch` low-passes each frame at 4 kHz
  before the NSDF. At 10 dB SNR, p95 went from 16 c to 1.3 c; at 5 dB SNR,
  misses went from 83/294 to 0. Clean frames cost ~0.2 c (max 0.4 c,
  0.7 c at 2048 samples). All existing noise-only, room-tone and mains-hum
  rejection tests pass unchanged.
- **Scoring impact.** Every room now reads a vibrato ~5 c flatter than before,
  i.e. centred. Scores for singers with wide vibrato may move slightly.

**Design (reuses what sing already has):**

- **Content.** Put lessons in `content/lessons/<stage>/<module>/<lesson>.md`
  with frontmatter, compiled by a new `scripts/compile-lessons.mjs` into a
  generated `lib/lesson-data.ts`. The book does the same with
  `content/book` → `scripts/compile-book.mjs` → `lib/book-data.ts`.
- **Routes.** `/learn/voice/[stage]/[module]/[lesson]`, plus stage and module
  index pages. Follow `app/book/[slug]/page.tsx`: `dynamicParams = false`,
  `generateStaticParams`, and `withCanonicalOpenGraph` with a canonical under
  `SITE_URL` and OG images (`lib/og.test.ts`). Add the pages to
  `app/sitemap.ts`, but never a noindex one (`lib/sitemap.test.ts`). Any FAQ
  needs visible headings (`lib/seo-section-structure.test.tsx`).
- **Entry points.** Add `/learn/voice` to the Learn tab's `also` list in
  `components/nav.tsx`, and link it from `/learn` (`VOCAL_LEARNING_PATHS`),
  `lib/llms-txt.ts` and the landing page. The footer's
  `MORE_FROM_SUEDE` "Voice curriculum on GuitarHub" link becomes sing's own
  page. Update the test that pins that anchor,
  `lib/internal-linking.test.tsx:156-166`.
- **Honest claims.** A lesson may only promise proof that a
  `measurable: "yes"` row in `contracts/suede-vocal.ts` supplies; everything
  else is worded as practice. Enforce it with a test modelled on
  `lib/programme-exit-tests.test.tsx`. The contract's `UNSUPPORTED_CLAIMS`
  already names claims the GuitarHub lessons make that sing can't measure
  (flow consistency, personal passaggio from a range scan, strain-free
  verdict, vibrato rate on cue, held harmony against a lead, pitch
  steadiness in the breath room). Those lessons get reworded, not copied.
  The GuitarHub lessons use a 35 c tolerance while sing uses
  `TOLERANCE_CENTS`; state which one applies.
- **Deep links.** Use only `contracts/suede-vocal.ts` `deepLinks` rooms and
  parameters (`/warmups?exercise=|routine=`, `/breath?drill=|routine=`,
