## Pitch-precision harness (S0a)

- `lib/audio/voice-fixture.ts`: a deterministic synthetic voice (harmonics,
  detune, vibrato, jitter, noise) plus a WAV encoder, shared by both layers
  below.
- `lib/audio/pitch-precision.test.ts`: C2–C6 at 44.1/48 kHz. Ceilings are
  measured values with headroom, and each figure is recorded in the file
  header.
- `npm run e2e:pitch` (`e2e/pitch-precision.mjs`): runs 12 cases through
  Chrome's fake microphone into `/studio`. It reads what `usePitch` heard via
  `window.__singPitchProbe`, a hook that does nothing unless the harness
  creates it. Usage and measured values are in `e2e/README.md`.

Measured: clean notes read within 0.2 c with no octave errors. At 10 dB SNR the
error reaches p95 16 c and max 31 c, and 2 of 294 frames are missed.

## S1 (pitch engine), built directly

- **Median bias fixed.** `lib/audio/median.ts` averages the two middle values.
  It's used by `usePitch`, ear-game note segmentation and the
  spectral-envelope F0, which all took the upper middle value before.
  Browser vibrato bias went from 5.5 c sharp to 0.7 c (ceiling 1.5 c).
- **Noise weak spot fixed.** `detectPitch` low-passes each frame at 4 kHz
  before the NSDF. At 10 dB SNR, p95 went from 16 c to 1.3 c; at 5 dB SNR,
  misses went from 83/294 to 0. Clean frames cost ~0.2 c (max 0.4 c,
  0.7 c at 2048 samples). All existing noise-only, room-tone and mains-hum
  rejection tests pass unchanged.
- **Scoring impact.** Every room now reads a vibrato ~5 c flatter than before,
  i.e. centred. Scores for singers with wide vibrato may move slightly.

## Environment notes

- In the cloud container, Playwright's pinned Chromium isn't installed. Run
  `npm run e2e:pitch -- --executable=/opt/pw-browsers/chromium`. Locally the
  run defaults to `channel: "chrome"`, like `e2e/run.mjs`.
- The e2e runner imports the TypeScript fixture directly, which needs
  Node 22.18 or newer.
- Don't `pkill -f "next start"` from a Bash tool call: the pattern matches the
  calling shell's own command line and kills it.
